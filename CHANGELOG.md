# Changelog

## 1.1.1

Krigsvold pages and examples no longer generate tables of contents by default. Optional author-supplied contents render inline above the reading content only with `show_toc: true`; no sidebar column or empty index margin is reserved. Heading IDs, routes, document content, application sidebars and controls remain available.

## 1.1.0

Accepted standalone Jekyll baseline with the approved responsive imagery and family-native example compositions. Its protected source release remains unchanged.
