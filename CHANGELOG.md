# Changelog

## 2.0.0

- **Breaking:** replace the former Jekyll, example, dashboard, and scientific page stylesheets with the canonical Core 3 `assets/css/krigsvold.css` file. Custom layouts must update their stylesheet links; see docs/migration-2.md.
- Keep Astro, React, and Jekyll canonical CSS identical and remove page-local styling.
- Adopt the reviewed dashboard navigation, ownership block, action priorities, article metadata, scientific workspace, and enlarged-text controls.
- Publish the verified source archive automatically after an accepted version reaches main.

## 1.1.1

Krigsvold pages and examples no longer generate tables of contents by default. Optional author-supplied contents render inline above the reading content only with `show_toc: true`; no sidebar column or empty index margin is reserved. Heading IDs, routes, document content, application sidebars and controls remain available.

## 1.1.0

Accepted standalone Jekyll baseline with the approved responsive imagery and family-native example compositions. Its protected source release remains unchanged.
