column. Search-specific rows now use the available result region and their own
bounded prose measure. No category/date metadata is manufactured to fill a column.
Search remains a browser-local demonstration, not a new hosted search service.

The report index uses the shared accessible label “Report sections” and existing
visible UI label “On this page”. Search's region label matches the paired Martlet
host. Neither change adds authored fixture prose or new controls.
