Observed source basis: krigsvold.org uses bounded Roboto/Roboto Slab editorial
content, purpose-specific navigation, and aligned source news/fellow regions.
The news DOM specifically aligns an image column with a second column containing
date, title, summary and action. It does **not** establish a literal release or
metadata-only register. Heading/content alignment here is an explicit contextual
translation of the source's regional principle and native grammar, not a claim
these exact documentation objects exist at the origin. Native grammar clauses
“Assign each region a job”, “Make hierarchy exact” and “Make scope visible” guide
these choices. No universal sidebar or universal Krigsvold table is inferred.

The three first-wave specimens retain their accepted implementations when this
branch integrates accepted `develop`. Homepage art/tint/ribbon, footer identity,
canonical shell/fonts, frozen archives and the complete shared dataset remain
unchanged. Workspaces and dashboards receive their own later task/state review.

stress-test. The generic inner region now appends “table” to its accessible name,
identifying the scroll target's purpose while preserving its caption, role, ID,

event/report before their later composition review; it does not claim their
archetype redesign is complete. The dedicated operations table is reviewed in
the later dashboard wave, not silently waived here.
