## Boundaries preserved

Existing Krigsvold dashboard-family rules already supply meaningful differences:
the 12rem contained sidebar, uppercase navigation, Roboto/Roboto Slab/number roles,
semantic navy/ice surfaces, category-wide chart region and source buttons remain.
No blanket panel rewrite, universal table mandate, decorative stripe, new control,
fixture field, chart type, authentication or backend is added.

The new scope wrappers are application translations of the native grammar's
scope/region/state rules, not claims that these exact dashboards exist at the
canonical origin. The administration arrangement follows the existing grammar's
collection/detail continuity: keep useful context visible when width allows,
then preserve source order when regions wrap. The original form and dialog
semantics are retained, including keyboard/focus and recoverable local drafts.

All canonical dataset and controller bytes must remain unchanged. In particular,
no recomputation logic, thresholds, dates, simulated state, CSV encoding, people
records, acknowledgements or source warnings are edited by this composition wave.
Focused browser verification covers the existing state transitions and source data
rather than interpreting a prettier initial screenshot as functional completion.

Homepage art/tint/ribbon, footer identity, core tokens/fonts and frozen archives
remain outside this work. The complete inherited suites remain required. A small
new operational gate is budgeted using measured preceding CI durations, not by
skipping engines, assertions or difficult states.
