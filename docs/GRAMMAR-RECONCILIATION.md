# Grammar reconciliation: first three specimens

Tracks workbench #91 and baseline audit PR #92. This is a bounded host translation,
not a new design system or a claim of complete origin fidelity. Canonical datasets,
routes, original section IDs, titles and prose, controls, and native behavior remain.

| Recipe | Task and source basis | Deliberate composition | What remains shared |
|---|---|---|---|
| FAQ | Identify a question's scope before opening its answer. Actual krigsvold.org/faq/ uses topic headings and native `details.krigsvold-faq`, with plus/minus state cues. | Two named scope regions align their headings beside native question disclosures. Both groups derive from the existing sequence; no table or new answer copy is introduced. | Four exact questions/answers, source order, independent native open/close, keyboard/no-JS operation. Group labels match the paired Martlet host. |
| Changelog | Compare releases without reconstructing where version/date metadata sits. The origin's `/news/` DOM and `news-listing` CSS align an image with date/title/summary/action content; native grammar asks common edges and exact scope. Version/date columns here are a contextual translation, not literal source changelog anatomy. | Each release aligns its existing version/date title against complete change prose. Dates are derived from the original title, with no invented status, change category, or migration field. | Original three IDs, full title text, dates, Markdown subheadings, release order and migration prose. |
| Component capabilities | Inspect four existing capability descriptions by stable scope, not pretend these fixtures contain the 22 React APIs. Origin regional comparison and the native grammar support aligned register entries. | Four always-visible scoped register rows use common title/content edges. No new collapse state hides anchor content. | The exact composition/metrics/behaviour/authority anchors and four complete paragraphs. The React catalog is supporting evidence, not the authority or a replacement dataset. |

Source evidence observed 2026-11-03: https://krigsvold.org/faq/,
https://krigsvold.org/news/ and their linked `/_astro/Page.7T515cpF.css`.
The source FAQ explicitly groups native disclosures; its CSS supplies the existing
plus/minus cue. The source news/fellow styles supply aligned regional patterns.
These observed objects do not establish a universal table or register requirement.

Native grammar: workbench `docs/languages/krigsvold/grammar.md`, especially
“Assign each region a job”, “Make hierarchy exact”, and “Make scope visible”.

`4ace73f9d74fd4ba9442a42117e56bbd0d4cd23e24bda211d5149f91b127074c`.
Roboto/Roboto Slab roles, semantic navy/ice roles, and original source controls
remain unchanged. Alignment of release fields and capability rows is an explicit
application translation, not evidence these exact objects exist at the origin.

The source shell/fonts, approved homepage panorama/tint/ribbon, footer identity,
frozen archives and shared fixtures are outside this wave. Later waves review
reading/reference, collections/detail/landing/dossier and workspaces/dashboard
by task. Unchanged anatomy requires its own rationale; mechanical family opposites
are not an acceptance criterion. Root/subpath and source archive checks accompany
keyboard/no-JS/forced-color/reduced-motion/print and actual masked visual review.

The first three specimens reuse the existing 74rem example-container envelope.
The previous 46rem envelope included both the local index and its gap, leaving
insufficient room for a scoped question/register region. Paragraphs retain their
existing 65–68ch bounds. This corrects the host composition without replacing the
canonical reading measure. Remaining document wrappers receive their own measured
review in the next wave rather than inheriting this decision automatically.
